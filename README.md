## 💡 我相信的「投资平权」

投资行业长期存在三层不对称：**信息不对称、工具不对称、专业能力不对称**。
结果就是：专业的人赚认知差的钱，普通人承担认知差的风险。

我做的事情，就是把这三层不对称一层层拆掉：

1. **信息层** — Invest dictionary 把晦涩术语变成普通人能读懂的话
2. **工具层** — SoloAdvisor 把投顾机构用的方法论开源给独立顾问和小白用户
3. **能力层** — Investment Pet / Invest Brain 把投资大师的决策框架沉淀为可调用的系统

不是让每个人变成基金经理，而是让每个都能用上基金经理级别的方法论。
