### 我相信的

**金融业不缺工具，缺的是会用工具的人。** AI 不会替代理财师，会用 AI 的理财师会替代不会用的。

**从实践中来，到实践中去。** 我不写「AI 可能会怎样改变金融」的预测文，只写「我用 AI 做了什么」的实录。每个项目、每篇文章，都是真实场景的副产品。

**产品是最好表达。** 一个跑通的工作流，胜过十篇分析报告。做出来，放出去，让用户告诉你对不对。
